A tela [Clientes duplicados](/clientes/duplicados) agrupa os clientes ativos com **mesmo nome e mesmo
telefone**. Para cada grupo, ela mostra qual cadastro será **mantido** e quais serão **removidos**.

## Ao mesclar

1. O cadastro mais antigo é o principal.
2. Os campos vazios do principal são preenchidos com os dados dos duplicados.
3. Os pacientes, as notas e as comunicações dos duplicados passam para o principal.
4. Os duplicados ficam inativos.

> [!ATENCAO]
> Confira o grupo antes de mesclar: a mesclagem não pode ser desfeita pela tela.
