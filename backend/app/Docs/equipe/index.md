A tela [Equipe](/equipe) reúne os profissionais e colaboradores da clínica.

## Cadastro

| Campo | Observação |
|---|---|
| **Pronome de tratamento** | ex.: Dr., Dra. |
| **Nome** * | nome do profissional |
| **CRMV** | sai na receita impressa |
| **Especialidade** | texto livre |
| **É veterinário** | aparece na agenda e assina prescrições e evoluções |
| **Situação** | Ativo ou Inativo |
| **Acesso ao sistema** | sem acesso, vincular um usuário já existente ou criar um login novo |

## Login do profissional

O vínculo entre o membro da equipe e o login é o que permite ao sistema saber **qual veterinário** está
registrando uma prescrição ou uma evolução.

> [!DICA]
> Criou um login sem senha? Ele recebe uma senha padrão. Peça para o profissional trocá-la no primeiro acesso.
