A tela [Todos os agendamentos](/agenda/todos) lista os atendimentos em cartões, com filtros que podem ser
combinados:

| Filtro | Para que serve |
|---|---|
| **Status** | pendente, confirmado, concluído ou cancelado |
| **Período** | data inicial e final |
| **Serviço** | só os atendimentos de um serviço |
| **Profissional** | só os atendimentos de um veterinário |
| **Busca** | nome do paciente, do tutor ou do serviço |

Cada cartão tem as mesmas ações da [agenda do dia](index.md#agenda-do-dia).
