O **Dashboard** é a primeira tela depois do login. Ele junta o que a recepção e o veterinário precisam
ver ao começar o dia.

## Indicadores

| Indicador | O que mostra |
|---|---|
| **Agendamentos hoje** | atendimentos marcados para hoje |
| **Pacientes ativos** | total de pacientes cadastrados |
| **Receita do mês** | soma das cobranças **pagas** com data de serviço no mês |
| **Pendentes** | agendamentos ainda com status **pendente** |

## Blocos

| Bloco | Conteúdo |
|---|---|
| **Agenda de hoje** | atendimentos do dia |
| **Próximos agendamentos** | atendimentos dos próximos 7 dias |
| **Serviços do mês** | quantos atendimentos de cada serviço no mês |
| **Atendimentos recentes** | últimos pacientes cadastrados |
| **Aniversariantes** | pacientes que fazem aniversário no mês |
| **Alertas de estoque** | produtos com quantidade igual ou abaixo do estoque mínimo |
| **Vacinas a vencer** | vacinas com próxima dose nos próximos 7 dias |
| **Pós-consulta** | atendimentos concluídos nos últimos 2 dias, bons para uma mensagem de acompanhamento |

> [!DICA]
> Os alertas de estoque dependem do **estoque mínimo** de cada produto. Veja [Estoque](../estoque/index.md).
